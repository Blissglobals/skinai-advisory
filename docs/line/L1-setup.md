# LINE 공식계정 기본 설정 (L1, AI 없이)

LINE 공식계정 관리자(LINE Official Account Manager)에서 직원이 직접 설정하는 내용입니다.
고객에게 보이는 문구는 번체(zh-TW)이고, 아래에 한국어 뜻을 달았습니다. 직원 검수 후 넣어주세요.

- `{사이트}` = 정식 도메인이 정해지면 바꿀 주소 (지금은 프리뷰 주소라 고객에게 쓸 수 없음)
- 응답 시간은 **한국시간 10:00–19:00(대만 09:00–18:00)** 을 가정했습니다. 다르면 문구 4곳을 같이 고쳐주세요.
- 응답 목표: 응답 시간 안에는 1시간 이내, 그 밖에는 다음 날 한국시간 오전 10시까지.

---

## 1. 응답 설정

| 항목 | 설정 |
|---|---|
| 채팅 | 켜기 (직원이 관리자 앱에서 직접 답변) |
| 응답 시간 | 한국시간 10:00–19:00 |
| 응답 시간 외 자동 응답 | 켜기 (아래 4번 문구) |
| 키워드 자동 응답 | 가능하면 켜기 (아래 3번). **채팅을 켠 상태에서 키워드 자동 응답이 동작하는지 확인 필요** — 안 되면 3번 문구를 관리자 앱의 "저장된 메시지(預設訊息)"에 넣고 직원이 눌러서 보냅니다. |

## 2. 친구 추가 환영 메시지

`{Nickname}` 자리는 관리자 화면의 "친구 표시 이름" 버튼으로 넣습니다.

```
{Nickname}您好！歡迎加入 Bliss Globals 🌿
我們協助您安排首爾合作診所的諮詢與預約，口譯與預約服務皆免費。

✔ 先做免費肌膚分析：一張自拍就能查看色斑、皺紋狀態（照片只在您的手機內分析，不會上傳）
✔ 想直接諮詢：請點選下方選單「預約諮詢」

客服時間：韓國時間 10:00–19:00（台灣時間 09:00–18:00）
客服時間內約 1 小時內回覆；其他時間的訊息，將於隔天台灣時間上午 9 點前回覆。

※ 本帳號提供預約與資訊說明，診斷與療程建議由合作診所醫師提供。
```

> 한국어 뜻: 친구 추가 감사 · 무료 통역·예약 · 무료 피부 분석 먼저(사진은 폰 안에서만 분석) · 바로 상담은 메뉴의 "예약 상담" · 응답 시간과 응답 목표 · 진단·시술 권유는 제휴 의원 의사가 합니다.

## 3. 상담 접수 양식 (키워드: `預約諮詢`)

메뉴의 "예약 상담" 버튼이 `預約諮詢`라는 글을 보내면 이 답이 나가게 합니다.

```
感謝您的諮詢！請複製下方內容、填寫後傳送給我們，可以更快為您安排 😊

【諮詢資料】
1. 想改善的肌膚困擾：
2. 預計來韓日期與停留天數：
3. 是否持有韓國健保或外國人登錄證（是／否）：
4. 有興趣的療程（不確定也沒關係）：
5. 希望的地區（弘大／江南／都可以）：
6. 預算範圍（可不填）：

※ 請勿傳送護照、身分證或付款資訊。
※ 諮詢資料的處理方式請參考隱私權政策：{사이트}/zh-TW/privacy
```

> 한국어 뜻: 아래를 복사해서 채워 보내주세요 · 고민 / 방문 날짜·체류 기간 / 한국 건강보험·외국인등록증 여부(혜택 대상 확인용) / 관심 시술 / 희망 지역 / 예산 · 신분증·결제 정보는 보내지 마세요 · 개인정보 처리방침 링크.

**확인 필요(법률):** 피부 고민은 건강 관련 정보라 민감정보로 볼 여지가 있습니다. "보내면 동의한 것으로 본다"는 방식으로는 별도 동의 요건을 못 채울 수 있습니다. L2(AI 접수)에서 동의 버튼을 넣을 때 같이 정리합니다.

## 4. 응답 시간 외 자동 응답

```
您好，目前為非客服時間，您的訊息我們已經收到了！
將於隔天台灣時間上午 9 點（韓國時間 10 點）前回覆您。

等待的時候，歡迎先試試免費肌膚分析 👉 {사이트}/zh-TW/analysis
```

> 한국어 뜻: 지금은 응답 시간이 아니고 메시지는 받았습니다 · 다음 날 대만 오전 9시(한국 10시)까지 답변 · 기다리는 동안 무료 피부 분석 링크.

크기: 큰 메뉴 6칸(2500×1686). 1번 칸은 색을 다르게 해서 가장 눈에 띄게 합니다.

| 칸 | 표시 문구 | 동작 | 연결 |

| 2 | 預約諮詢 | 텍스트 보내기 | `預約諮詢` (3번 양식이 답으로 나감) |
| 3 | 療程介紹 | 링크 | `{사이트}/zh-TW/treatments` |
| 4 | 合作診所 | 링크 | `{사이트}/zh-TW/clinics` |
| 5 | 首爾旅遊指南 | 링크 | `{사이트}/zh-TW/guide` |
| 6 | 常見問題 | 링크 | `{사이트}/zh-TW#faq` |

메뉴 이미지는 사이트 디자인(크림 배경·딥그린)에 맞춰 따로 만들어 드릴 수 있습니다.

## 6. 직원용 저장 메시지 (預設訊息)

**접수 확인**
```
已收到您的諮詢資料，謝謝！我們會確認合作診所的可預約時間後再通知您。
```
(접수 받았고, 의원 예약 가능 시간을 확인해서 다시 연락드립니다.)

**의학적 질문을 받았을 때**
```
這個問題需要由醫師看過您的狀況後判斷，我們會在預約諮詢時幫您轉達給醫師。
```
(의사가 직접 보고 판단해야 하는 질문이라, 진료 상담 때 의사에게 전달하겠습니다.)
→ 직원은 시술 추천·효과·부작용 판단을 하지 않습니다. 가격은 의원이 공개한 가격만 안내합니다.

**혜택 대상이 아닐 때** (한국 건강보험 또는 외국인등록증이 있는 경우)
```
不好意思，免費口譯與預約服務僅提供給短期來韓的旅客。您可以直接聯絡診所預約，診所資訊請參考：{사이트}/zh-TW/clinics
```
(무료 통역·예약은 단기 방문객 대상입니다. 의원에 직접 문의해 주세요.)
